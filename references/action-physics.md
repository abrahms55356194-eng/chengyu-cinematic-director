# 动作物理

动作卡逐项填写：起始姿态与支撑脚 → 发力及重心转移 → 轨迹 → 接触/擦过 → 接收者响应 → 环境响应 → 制动与结束姿态。指定左右手、道具重量感、接触点和屏幕方向。禁止接触前受击、无支撑滑行、无原因换手、重复起手。

|动作|可见因果与结束条件|
|---|---|
|奔跑|脚掌交替接地推进，躯干略前倾，停止时缩步制动；终点双脚有稳定支撑|
|跳跃|屈膝蓄力、离地、抛物线、落地屈膝吸收；不能空中二次无因加速|
|跌倒|失衡方向先明确，身体随后转移，触地后衣料与尘土才响应|
|格斗|一次清晰攻防；准备、攻击轨迹、接触、受力后退、恢复分开；不靠模糊隐藏接触|
|武器动作|固定握持手，肩肘随重量运动；挥动后需制动，后坐反应发生在发射后|
|舞蹈|节拍对应落脚与髋部转移；转身前明确轴脚，结束保持平衡|
|追逐|先锁双方距离与方向；拐弯先减速倾身，再重新加速，障碍不可凭空消失|
|机械操作|手接触控制器后机械才运动，行程与限位明确，反作用传到支架|
|日常动作|手先接近、握牢、再提物；放下后接触桌面才松手|
|生物运动|按肢体结构安排支撑序列；大质量停止更慢，地面反馈与落脚同步|

高速镜头用跟随速度维持主体可读，前景视差快于远景；背景沿运动方向拖影，不能让脸与背景同等糊。生成失败先降低同镜动作数量，再考虑分镜。这里是影像动作设计，不提供真实危险动作执行方案。
