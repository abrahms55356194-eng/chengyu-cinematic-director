# 人物表演

角色卡：唯一 ID、参考身份、年龄范围、体型、面部结构、发型、服装；行为卡：常态姿态、步态、呼吸、眼神习惯、说话节奏、情绪表达方式。未知项使用稳定且明确标为设计的描述，不推断真实人物身份。

逐场使用 Objective → Obstacle → Tactics → Beats → Subtext：想获得什么、谁阻挡、如何应对、策略在哪里转折、言语未说出的张力。把每个节拍转换成观察得到的行为，不把心理标签直接当动作。

例如等待坏消息：右手停在杯柄上；吸气被打断；视线先落在对方面部，再低到桌缘；手仍未离杯；说话前吞咽一次。节拍必须由收到的信息触发，不能让反应先于刺激。

FACS 仅用于需要精确区分表情的修订；优先写眉间收紧、上眼睑抬起、唇角绷紧。动作单元不是情绪真值，不从 AU 编号推出必然心理。特写减少同时发生的面部动作，保留自然眨眼与短暂视线转移。

对白逐字绑定说话者和时间段，旁人只听、呼吸或做剧情允许的反应；长句超出时长则延长/拆组，不能擅自删词。结束时记录嘴是否闭合、视线目标、双手位置、支撑脚和呼吸状态，交给下一镜。
