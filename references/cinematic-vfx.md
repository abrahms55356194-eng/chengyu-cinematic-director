# 条件式 VFX

剧本没有要求则不启用。不添加新事件。LEVEL 1 克制局部真实效果；LEVEL 2 商业电影级多元素但主体可读；LEVEL 3 大尺度多层环境响应，仅剧情与用户需要时选择。

每个重要效果填写 Source → Trigger → Formation → Propagation → Interaction → Receiver Response → Environment Response → Dissipation → Residue。幻想机制可以虚构，但一旦设定就保持因果、尺度与时间规则。

|分类与可调用类型|机制设计重点|
|---|---|
|能量：Energy Beam / Energy Pulse / Shockwave / Plasma / Energy Explosion / Electric Arc / Force Field|指定源与触发，束/脉冲沿明确路径传播；电弧连接端点，力场有边界；接触后才反馈，能量衰减后留有限余辉，不全屏乱闪|
|超自然：Magic Formation / Runes / Spiritual Energy / Divine Manifestation / Spatial Rift / Teleportation / Dimensional Distortion|符文依附表面或固定平面；裂隙有边界；传送须建立消失/出现规则和终点，不能作为普通动作瞬移借口|
|破坏：Explosion / Building Collapse / Debris / Shattering / Fracture / Impact / Dust Shockwave|先破坏源和承重失效，再裂纹传播、块体脱离、重力下落、接触扬尘；大块先沉降细尘后悬浮，废墟持续|
|自然：Fire / Smoke / Rain / Water Simulation / Lightning / Wind / Sandstorm / Snow|火由燃烧处生长，烟受浮力与风；雨雪风向统一，水有边界和接触飞溅，闪电照明同步|
|变形：Mechanical Transformation / Creature Transformation / Material Conversion / Growth / Deformation|指定原结构到目标结构的连续映射；铰链/肌肉驱动，体积或物质来源明确，接触点保留，不以闪光掩盖跳变|
|实体：Giant Creature / Colossal Entity / Creature Reveal / Skin and Muscle Simulation / Scale Comparison|固定参照物与遮挡建立尺度；骨骼带动肌肉皮肤，落脚后地面反馈，远近大气层次稳定|

融合检查：遮挡顺序与深度；反射与反弹光有接收面；阴影背离源；体积光只在介质内；运动模糊、景深、色彩、颗粒和曝光与镜头一致。效果遮掉关键动作时降低密度或另设反应镜头。

例：门内闪电装置被按下 → 两端电极积亮 → 电弧连接电极而不随机扫人 → 金属架反射短闪 → 近墙瞬间偏冷 → 电源关闭后电弧消失 → 电极留下轻烟。镜头中若墙被门挡住，该处不能同步受直射。
