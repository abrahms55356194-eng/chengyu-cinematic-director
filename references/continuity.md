# 连续性台账

每镜记录 start/end 两份状态：角色位置、身体朝向、视线目标、左右手持物、道具状态、光源方向、摄影机位置、声音状态。上一镜 end 应与下一镜 start 相容；明确的时间跳跃、交接动作或场景转换才能解释差异。

检查顺序：身份 → 服装 → 道具所属/左右手 → 空间轴线 → 动作阶段 → 光线 → 声音。不要把上一镜动作结束重置为下一镜再次起手。切特写也保留位置与视线，不能通过省略描述暗中移动人物。

台账例：S1 结束，A 在门内右侧朝西，右手持折叠信封，左手扶门，窗光来自北侧；S2 开始应保持这些状态，除非明确展示放手/交接。画外声音继续时写持续状态，不能每次切镜重启音乐。

参考资产字段：ID、职责、允许继承、禁止继承、可信范围。人物图只锁身份，不继承背景；场景图锁可见布局，不改人物；动作视频不覆盖服装；音频只锁指定音色/节奏。被遮挡的空间标未知，使用保守机位或补参考，不虚构其已被证明。
